# Paradise Nursery Shopping Application

Paradise Nursery is an online shopping cart application for plant enthusiasts, built using React and Redux Toolkit.

## Features
- **Landing Page**: Overview of the nursery with a "Get Started" button.
- **Product Listing**: Browse houseplants categorized by air-purifying, aromatic, and low-maintenance plants.
- **Dynamic Cart**: Add plants to cart, adjust quantities, calculate sub-totals and grand totals, and remove items.
- **State Management**: Fully powered by Redux Toolkit for seamless state updates.

## Tech Stack
- React
- Redux Toolkit
- CSS3 / HTML5
